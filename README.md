# MCP Stocks Analyzer

A Python-based tool for analyzing stock market data using Google News.

## Description

This project provides functionality to analyze stock market data by fetching and processing news from Google News.

## Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/mcp-stocks-analyzer.git
cd mcp-stocks-analyzer

# Install dependencies (if you have requirements.txt)
pip install -r requirements.txt
```

## Usage

```python
python googlenews.py
```
